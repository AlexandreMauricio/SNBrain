## Fetching notes

- **Platform Administration PDF (Australia)**: `servicenow-australia-platform-administration-enus.pdf`, 3,011 pages, kept outside the vault (the user's Downloads folder; too large for git). Read by extracting text per outline section with Python `pypdf` (`PdfReader`, `outline`, `extract_text`), stripping the three footer lines of each page, then reading the text files in chunks. Tables in the PDF come out as broken lines, so column alignment has to be inferred. Rows in the Processed table give the PDF section title and page range instead of a URL.
- **IT Service Management PDF (Australia)**: `servicenow-australia-it-service-management-enus.pdf`, 4,075 pages, kept in the user's Downloads folder. Same extraction method. Read in full: Incident, Incident Communications, Problem, Request, Service Level Management, On-Call, Task Outage, Release, Expense Line, Product Catalog. A first pass read the core processes in full and the rest at overview depth; a second pass on 2026-10-02 read every remaining chapter line by line (rows marked "(full read)"). The older overview-depth rows are kept for history. This guide calls the generative AI product "ServiceNow Otto" where earlier releases say Now Assist.
- **Docs site in bulk (Fluid Topics API)**: the product docs site answers plain HTTP requests without a browser. List of guides: `https://www.servicenow.com/docs/api/khub/maps`. Table of contents of one guide: `.../api/khub/maps/<mapId>/toc`. Text of one topic: `.../api/khub/maps/<mapId>/topics/<contentId>/content` (HTML; strip the tags). The Australia Build workflows guide is map `HGWDpzjgkfvaJWTdMzNy2w` (741 topics). Used on 2026-10-08 to read the chapters that the Build workflows PDF does not contain; each chapter was saved as text, repeated boilerplate lines removed, and read in full. Rows in the Processed table give the chapter and its first page URL.
